# Cron configuration for instant marketplace updates
# Add these to your cron scheduler (Vercel Cron, GitHub Actions, etc.)

# Run instant sync every 30 seconds for immediate updates
# This checks the last 50 blocks for any new activity
*/30 * * * * curl -X POST https://your-domain.com/api/instant-sync -H "Content-Type: application/json" -d '{"checkRecentBlocks": 50}'

# Run full sync every 5 minutes as backup
*/5 * * * * curl -X POST https://your-domain.com/api/sync-listings -H "Content-Type: application/json"
